# Implementation prompt

```text
Implement this feature against the relevant Boring specification. Before coding,
read the linked edge cases and identify which rules apply to this architecture.
After coding, verify each applicable scenario, add regression tests in the project's
own test style, and report any rule intentionally unsupported or any
decision_required item that needs product input. Cite Boring IDs in the summary.
```

The underlying prompt is vendor-neutral and works in `AGENTS.md`, `CLAUDE.md`,
Codex instructions, Cursor rules, or a normal review checklist.
